# Superblocks Deployment Playbook (draft)

An interactive draft of a customer deployment playbook for Superblocks, from signed contract to renewal. Answer the account setup questions and the timeline, stage steps and risk flags adapt to that customer.

Drafted by Sardar Ahmar Wasif and built with Claude Code. Not an official Superblocks product. All sample data is fictional. Product details are based on the public Superblocks docs as of October 2026.

Static site: a single `index.html`, deployable to Vercel with no build step.
